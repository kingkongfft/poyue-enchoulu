# 鲁迅式散文优化（poyue-essay-style）

本技能是本仓库 `poyue-enchoulu`（破夜·沉默之声）的**仓库级技能**。它用于把投稿人原始的、朴素的、往往"说不出口"的话语，**优化为具有鲁迅行文风骨的定稿散文**。

## 何时使用

- 收到一篇投稿 / 草稿，需要按本集风格定稿时；
- 已有散文，需要按鲁迅风格润色、打磨、重写时；
- 用户在 AGENTS.md 红线规则要求下，"对最终成文调用本技能"时。

## 优化原则（先立再改，不失本心）

优化**不是**用华丽的词藻覆盖作者的原话，而是让作者本来的思想更有力量地立起来：

1. **保意**——先抓住投稿人真正的思想、情绪与现实处境，任何修辞都不能扭曲它。
2. **保安全**——遵循 AGENTS.md 的匿名与安全底线：不署名、不定位、不泄密、不夸大、风险内容模糊化。
3. **保个性**——能用作者自己的一两个鲜活句子，就不要换成你的"文雅"说法。

## 鲁迅式行文要点（本技能的审美基准）

鲁迅的文字何以有锋，可从以下维度把握：

- **冷而热**：表面冷峻、克制、不煽情，内里却是炽热的关切。忌喧嚣，禁滥情。
- **讽刺与自嘲**：常以反语、自嘲、拷问自己的方式刺破虚伪；若文章需要，宁可自嘲，不要骂街。
- **痛感与细节**：从最贴身的、具体的、往往痛的细节切入，而非空谈道理。
- **短句、峭拔**：多用短句、转折、设问与反诘；删掉一切可有可无的形容词与连接词，句句当立。
- **意象与象征**：善用一个能立住的意象（铁屋子、窗、灯、夜、沉默、影子）贯穿全文，让抽象落在具体上。
- **批判指向结构**：矛头对准现象、制度与惰性，而非某个具体的人；不留刻薄，只留清醒。
- **留白与余味**：结尾不必把话说尽，留一刻沉默与回响，正如"夜正长，路也正长"。

## 优化工作流

对每一篇要定稿的散文，按以下步骤进行：

1. **通读归旨**：用一两句话概括全文的核心思想；若抓不住，先不急着动笔。
2. **定意象**：决定是否引入/保留一个贯穿全文的意象作为骨。
3. **逐段淬炼**：保留作者原句中最有力者；把啰嗦处收紧，把滥情处冷却，把空话处删去；在需要处加入反诘、转折或自嘲。
4. **检查分寸**：批判是否仍指向结构而非个人？是否冷而不冷漠、热而不滥情？
5. **匿名复核**：跑一遍 AGENTS.md 的安全底线，识别并模糊化任何可能反推身份的信息。
6. **核对红线**：本文是否会被**独立保存为一个 `.md` 文件**？（此步骤在保存时完成，见下）

> 提示：鲁迅从来不用吓人的口号打头。真正震人的，往往是平静到让人发冷的那一句。让开第一刀冷静，让结尾留白。

## 保存要求（配合 AGENTS.md 红线规则）

- 优化完成的**定稿**必须**另存为一个独立的 Markdown 文件**（默认放 `essays/` 目录），不得并进其他文件。
- 命名：`essays/<序号或日期>-<主题词>.md`，如 `essays/07-影子.md`。
- 文件顶部可加 front-matter（标题、写作季节；**不**含任何作者信息）。
- 若同时有草稿，注明来源文件或仅保留定稿即可，定稿独立成文。

## 检查清单（优化完成后逐项确认）

- [ ] 保留了作者的核心思想与情绪？没有扭曲、没有替作者虚构？
- [ ] 语言冷峻、凝练、有锋；短句为主，删尽了空话与得体的腔调？
- [ ] 有一个能立住的意象贯穿（或克制地使用）？
- [ ] 批判指向结构/现象，而非某个具体个人；冷而不冷漠？
- [ ] 通过了匿名与安全底线复核？
- [ ] 定稿已被**独立保存**为 `essays/` 下的 `.md` 文件？
